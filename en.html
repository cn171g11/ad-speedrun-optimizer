Antimatter Dimensions — Speedrun Optimizer

From 10 AM to the end of the game, every number traced back to source code.

What this is

A set of interactive tools that reverse-engineer Antimatter Dimensions (web / Steam / Android) from its open source, simulate the progression tick-by-tick, and turn it into optimal purchase-by-purchase route plans. Every number is either derived from a formula (with the source file cited) or explicitly flagged as "guide-measured" / "estimated". We never disguise an estimate as a computation.

Note: the detailed pages (stage-1 tool, S1 operation tables, simulations) are currently in Chinese. This page is an English summary of the key results. The core tables use numbers/symbols that are language-independent.

Headline result — the S1 optimization (1 IP → Break Infinity)

The real bottleneck is not the challenges: it's unlocking "Break Infinity", which (from BreakInfinityButton.vue) requires Autobuyer.bigCrunch.hasMaxedInterval — maxing the Big Crunch autobuyer interval (reward from Challenge 12). The interval ladder costs 1 + 2 + 4 + … + 16384 = 32,767 IP, and pre-break each crunch yields exactly floor(308/div × totalIPMult) = 1 × IPmult. So the segment is a fixed 4,081-crunch grind, and the only levers are crunch time and the purchase order.

Honest limits

Simulated, and cross-checked: stage 1 (10 AM → first Infinity), S1 (1 IP → Break Infinity), and the pre-break challenges — all verified against the source and speedrun.com records.

Skeleton only (no simulation): Eternity → Reality → Cel-1 → Cel-7. These add hundreds of mechanics (Time Studies, Eternity Challenges, dilation, glyphs, celestials) with no closed-form model; we give the official milestone skeleton and guide thresholds, not fake numbers.

Assumptions to know: the "×2 dimension" Android multiplier comes from the reference optimizer (menelajjj/ad-dimboost-optimizer) and is supported by the WR within 8%; the "ad bonus = global ×2 speed" from the guides conflicts with a ×4 reading, so we list two Android tiers and flag the contradiction.
