这一段在干什么（一句话）

你手上有 1 IP，目标是通关 C9。中间没有任何"捷径"：每一次大坍缩只给 1 × IP倍率 的 IP （因为封顶时 IP = floor(1.7817)），所以整段就是一个循环 —— 刷无限拿 IP → 买无限升级 → 单次无限变快 → 更快地拿 IP。 核心指标只有一个：单次无限耗时。它每掉一档，刷 IP 速率就上一个数量级。

最重要的隐藏门槛（源码级）：「IP 翻倍」和「离线 IP」两个升级的解锁条件是 Achievement(41) = 买满 16 个无限升级。也就是说 —— 在买满 16 个无限升级之前，你每次无限都只能拿到 1 IP； 买满之后，10 IP → ×2、100 → ×4、1e3 → ×8、1e4 → ×16，收益才开始指数增长。 这解释了攻略为什么先咬牙买 20/40/80/300 IP 的四个 skipReset，而不是先买那个只要 10 IP 的翻倍。
