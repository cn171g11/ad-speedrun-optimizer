这一段在干什么（一句话）

你手上有 1 IP，目标是通关 C9。中间没有任何"捷径"：每一次大坍缩只给 1 × IP倍率 的 IP （因为封顶时 IP = floor(1.7817)），所以整段就是一个循环 —— 刷无限拿 IP → 买无限升级 → 单次无限变快 → 更快地拿 IP。 核心指标只有一个：单次无限耗时。它每掉一档，刷 IP 速率就上一个数量级。
另外一条同样重要的规则：挑战不要在解锁那一刻就打 —— 见下方「挑战起始时机」，先把 IP 刷到买得起无限维度（ID），再进挑战，总耗时反而更短。

最重要的隐藏门槛（源码级）：「IP 翻倍」和「离线 IP」两个升级的解锁条件是 Achievement(41) = 买满 16 个无限升级。也就是说 —— 在买满 16 个无限升级之前，你每次无限都只能拿到 1 IP； 买满之后，10 IP → ×2、100 → ×4、1e3 → ×8、1e4 → ×16，收益才开始指数增长。 这解释了攻略为什么先咬牙买 20/40/80/300 IP 的四个 skipReset，而不是先买那个只要 10 IP 的翻倍。

★ S1-M 手动路线：1 IP 之后头几次大坍缩怎么点（还没有自动化）

有了 IU11/IU12 之后，第一阶段的流程不能照搬了 —— 倍率来源变了， 买满 10 个的倍率从 ×2 变成 ×2.2，最优的"提升→星系"节奏也随之改变。 更重要的是：这几跑纯手动反而比开自动购买器快。
源码事实：维度自动购买器默认间隔是 500~1200 毫秒（第 1 维 500ms、第 8 维 1200ms）， 而 PC 按住「Max」是按帧购买（33ms）——快 15~36 倍；买齐 8 个自动购买器还要花 1e40 ~ 1e110 反物质，并且只有通关 C1~C8 之后它们才变成"可升级"。 所以头几次大坍缩的最优解就是：按住 Max + 手动到点按提升/星系/献祭。

★ 挑战起始时机：为什么"不能一解锁就进"

你提到的那点正是这一段的隐藏杠杆：进挑战不会丢掉你已经买的无限维度。 源码里进入挑战 = 一次强制大坍缩，它会清掉反物质 / 8 个反物质维度 / 计数频率 / 维度提升 / 星系， 连无限之力都归 0 —— 但 每个 ID 的购买次数永久保留，ID 数量只是回到 baseAmount = 10 × 已购次数。而 ID1 的倍率是 50^已购次数， 无限之力又给全部反物质维度 ×IPower^7。所以"先攒钱买 ID，再进挑战"能把挑战时长压掉一到两个数量级。
